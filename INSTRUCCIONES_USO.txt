SIMULADOR PYTHON DE KEYTOOL - INSTRUCCIONES DE USO
=================================================

1. Abrir la terminal
--------------------
Abre PowerShell o CMD en la carpeta del proyecto.
Si tienes el entorno virtual activo, puedes usar directamente `python mykeytool.py`.
O bien invocar el intérprete del entorno virtual:

    .\.venv\Scripts\python.exe mykeytool.py --help

2. Instalar dependencias
------------------------
Si aún no las has instalado:

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install cryptography

3. Generar una clave y crear el almacén (--genkey o --genkeypair)
-----------------------------------------------------------------
Ejecuta:

    python mykeytool.py --genkeypair

El programa solicita:
- Una contraseña para el KeyStore y su confirmación (mínimo 8 caracteres).
- Un alias para identificar la clave (ejemplo: `servidor-web`).
- Los datos del titular (DName):
  * CN: Nombre común / Dominio (ej. monlau.es)
  * OU: Unidad organizativa (ej. Informatica)
  * O:  Organización (ej. Monlau Formacio)
  * L:  Localidad (ej. Barcelona)
  * ST: Provincia o estado (ej. Barcelona)
  * C:  Código de país ISO de 2 letras (ej. ES)
- Una contraseña propia para la clave privada del alias y su confirmación.

Al terminar, se genera el par RSA de 2048 bits y un certificado autofirmado X.509 en `keystore.pystore`.

4. Crear una solicitud CSR (--certreq)
---------------------------------------
Ejecuta:

    python mykeytool.py --certreq

Solicita:
- Contraseña del KeyStore.
- Alias de la clave creada.
- Contraseña de la clave privada de ese alias.

El resultado es el archivo PEM `<alias>.csr` listo para enviar a una Autoridad de Certificación (CA).

5. Listar las entradas del almacén (--list) [Ampliación]
--------------------------------------------------------
Ejecuta:

    python mykeytool.py --list

Introduce la contraseña del KeyStore y verás:
- Listado de todos los alias.
- Tipo de entrada (PrivateKeyEntry).
- Propietario (Distinguished Name).
- Huella digital del certificado en formato SHA-256.

6. Exportar el certificado público (--exportcert o --export) [Ampliación]
-------------------------------------------------------------------------
Ejecuta:

    python mykeytool.py --exportcert --alias servidor-web

Genera el archivo `servidor-web.crt` en formato PEM (X.509), instalable en navegadores y sistemas operativos.

7. Inspeccionar un certificado o CSR (--printcert) [Ampliación]
---------------------------------------------------------------
Ejecuta:

    python mykeytool.py --printcert --file servidor-web.crt
    python mykeytool.py --printcert --file servidor-web.csr

Muestra de forma legible el sujeto, emisor, validez, algoritmo de clave, algoritmo de firma y huellas digitales.

8. Eliminar una clave (--delete) [Ampliación]
---------------------------------------------
Ejecuta:

    python mykeytool.py --delete --alias servidor-web

Pide la contraseña del almacén y confirmación previa (s/n) antes de eliminar la entrada.

9. Rutas personalizadas del almacén (--store o --keystore)
----------------------------------------------------------
Puedes usar `--store` o `--keystore` para trabajar con otra ruta o nombre de archivo:

    python mykeytool.py --genkeypair --keystore mis_claves.pystore
    python mykeytool.py --certreq --keystore mis_claves.pystore

10. Ejecutar las pruebas automatizadas
--------------------------------------
Para verificar que todo funciona correctamente:

    python -m unittest discover -s tests -v
